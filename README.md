# 信号デコーダ

手旗信号・発光信号・モールス信号をブラウザで解読する、学習・練習用の Web アプリです。

公開ページ: https://hanaphoto.github.io/signal-decoder/
説明書: https://hanaphoto.github.io/signal-decoder/manual.html

## できること
- **モールス**: 符号テキストの解読、大きな電鍵ボタンのタップ解読（押す長さで短点／長点、離す長さで区切りを自動判定）、文字→符号の逆変換と音再生。欧文／和文（カナ）切替、濁点・半濁点の合成、SOS の特別表示
- **発光**: 点滅を見ながらボタンを押し続けて記録・解読（モールスと共通エンジン）、文字→画面点滅での送信練習
- **手旗・欧文（セマフォア）**: 左右2つの8方向パッドで旗位置を選んで解読。数字モード、左右反転（鏡像）対応、文字→旗位置の逆変換
- **手旗・和文**: 原画ボタン（0〜14・逆2）を押した順に記録し、組み合わせからカナを解読。入力途中の候補表示、濁音・半濁音の合成、カナ→原画の逆変換
- **一覧表**: 4種の符号表を文字で検索

## 仕様
- 単一 HTML ファイル（`index.html`）で動作。ビルド不要
- 入力はすべて端末内処理で、外部送信しません。オフラインでも動きます（Service Worker）
- 符号表の出典: 欧文モールス＝ITU-R M.1677、和文モールス＝無線局運用規則 別表第1号、和文手旗＝日本船舶信号法（Wikipedia「手旗信号」で照合）、欧文セマフォア＝標準ペア表

## 注意
学習・練習用です。実際の航海・救難通信の代替にはなりません。
